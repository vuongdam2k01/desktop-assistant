## 1. Executive Summary

The monorepo foundation for Desktop Assistant has been fully established using **pnpm workspaces (v12.4.1)**, **Turborepo (v2.10.12)**, and **Node.js (v24.21.0)**. The implementation establishes all workspace boundaries, code-generates `@desktop-assistant/contracts` from the live specification corpus (`docs/spec/**/contracts/`), implements the two-window Electron desktop shell with additive extension seams, delivers the Fastify backend service with real PostgreSQL pool probing and rate-limiting, provides target-only native capability skeletons, establishes four non-vacuous build checks, and configures cross-platform CI with unsigned packaging verification.

The user-owned specification and planning files under `docs/spec/` remain completely untouched and preserved.

### SQL DDL Parsing & Type Mapping

The custom SQL parser parses balanced `CREATE TABLE` blocks and maps data types with precision safety:
- `TEXT`, `VARCHAR`, `TIMESTAMPTZ`, `TIMESTAMP`, `UUID` -> `string`
- `INTEGER`, `REAL`, `NUMERIC`, `DOUBLE PRECISION` -> `number`
- `BIGINT`, `BIGSERIAL` -> `string` (precision-safe mapping, e.g. `causal_position` / `origin_sequence`)
- `BOOLEAN` -> `boolean`
- `JSON`, `JSONB` -> `unknown`
- `BLOB`, `BYTEA` -> `Uint8Array`
- Primary key and `NOT NULL` columns are non-null; optional columns map to `type | null`.
- Fails closed on unrecognized column types (zero `any`).

## 4. Four Hard Invariant Build Checks (`tooling/build-check`)

All four build checks operate under zero-tolerance rules (any violation produces non-zero exit code with stable prefix):

1. **`HARNESS_PIN_VIOLATION`**: Requires `@earendil-works/pi-agent-core@0.85.1` and `@earendil-works/pi-ai@0.85.1` in `apps/desktop/package.json` and as the sole resolutions in `pnpm-lock.yaml`. Rejects any reference or resolution matching `@oh-my-pi/*`.
2. **`SQLITE_BINDING_VIOLATION`**: Requires `better-sqlite3@13.0.3`, rejects resolutions `< 13`, and verifies the physical existence of `prebuilds/<platform>-<arch>.node` in the installed package.
3. **`NATIVE_PACKAGING_VIOLATION`**: Statically enforces `asar: true`, `asarUnpack: ['**/*.node']`, `npmRebuild: false`, and `mac.x64ArchFiles: '*.node'` in `apps/desktop/electron-builder.yml`. In artifact mode, requires at least one physical `.node` outside `app.asar` and verifies no addon exists only within the archive.
4. **`BOM_VIOLATION`**: Scans all F0-owned configuration files and manifests (`package*.json`, `tsconfig*.json`, `.gitignore`, `turbo.json`, `pnpm-workspace.yaml`, `.prettierrc.json`, `eslint.config.mjs`, `vite*.config.ts`, `electron-builder.yml`, `.github/**/*.yml`, `Cargo.toml`, `binding.gyp`, `compose.yaml`, `.env.example`) for the UTF-8 Byte Order Mark (`0xEF, 0xBB, 0xBF`). Invoked directly by `pnpm lint`.

### Fixture Testing Proof

`tooling/build-check/tests/build-check.test.ts` executes 8 tests asserting `exitCode !== 0` on negative fixtures:
- Mispinned harness package: failed with `HARNESS_PIN_VIOLATION`
- Forbidden `@oh-my-pi/` dependency: failed with `HARNESS_PIN_VIOLATION`
- Mispinned `better-sqlite3`: failed with `SQLITE_BINDING_VIOLATION`
- Missing `asar: true`: failed with `NATIVE_PACKAGING_VIOLATION`
- Packed `.node` without physical unpack: failed with `NATIVE_PACKAGING_VIOLATION`
- Physical unpacked `.node` present: passed with `BUILD_CHECK_PASSED`
- UTF-8 BOM in `package.json`: failed with `BOM_VIOLATION`
- Current workspace: passed all 4 checks with `BUILD_CHECK_PASSED`
